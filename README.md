# Calculadora Electron

Una aplicación de escritorio simple de **calculadora** desarrollada con
[Electron](https://www.electronjs.org/), HTML, CSS y JavaScript.

------------------------------------------------------------------------

## 🚀 Instalación y ejecución

1.  Clona este repositorio:

    ``` bash
    git clone https://github.com/nernunnzar/calculadora-electron.git
    cd calculadora-electron
    ```

2.  Instala dependencias:

    ``` bash
    npm install
    ```

3.  Ejecuta la aplicación:

    ``` bash
    npm start
    ```

------------------------------------------------------------------------

## 📌 Características principales

-   Operaciones básicas: suma, resta, multiplicación y división.
-   Interfaz ligera y minimalista.
-   Funciona como aplicación de escritorio multiplataforma.

------------------------------------------------------------------------

## 📂 Estructura

-   **main.js** → Punto de entrada de Electron.
-   **preload.js** → Script previo de seguridad.
-   **index.html** → Interfaz principal.
-   **styles.css** → Estilos visuales.
-   **script.js** → Lógica de la calculadora.
-   **package.json** → Configuración y dependencias.
